Команда /medicines
Кнопка "Ручное изменение остатков"

Пользователь вводит несколько начальных букв наименования товаров и нажимает Интер.
Бот фильтрует препараты из базы данных vetmarket.db таблицы medicnes по полю Name.
Пользователь выбирает товар и нажимает Интер.
Бот открывает карточку товара, где указаны все его характеристики: Фото по ссылке в самао верху карточки
Пользователь с клавиатуры вводит остаток товара.
Бот заменяет значение поля "Remaninder" на значение, введенное пользователем и выдает отчет: "Остаток препарата <наменование>:" <количество>
