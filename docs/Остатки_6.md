Команда /medicines
Кнопка "Удаление одного препарата"
Скрипт сохранить в файле src/steps/step_six.py

Пользователь вводит несколько начальных букв наименования товаров и нажимает Интер.
Бот фильтрует препараты из базы данных vetmarket.db таблицы medicnes по полю Name.
Пользователь выбирает товар и нажимает Интер.
Бот открывает карточку товара, где указаны все его характеристики препарата. 
Бот спрашивает: "Удалить препарат?"; Предлагает пользователю две кнопки "Да" и "Нет".
При выборе пользователем "Да" выбранный препарат удаляется из базы данных и база данных оптимизируется.
