Полученный скрипт записать в файл src/steps/step_two.py. Связать файл скрипта с файлом bot.py

В бот загружается .xlsx, .xls или .ods документ. В документе не должно быть наименований столбцев.
Бот считывает по очереди все строки документа по столбцу "A", производит поиска в поле "Name" базы данных vetmarket.db. 

В случае если значение столбца "A" в поле "Name" нашлось, бот заменяет значение в поле "Remainder" значеним из второго по очереди столбца, стоящего рядом со столбцом "A", это может быть столбец "B", "C", "D", "E", "F", "L" или какой-то другой.

В случае, если значение столбца "A" не нашлось в базе данных, бот ничего не делает, запоминает значение столбца "A" и переходит к следующей записи.

В конце обработки загруженного листа, бот выдает пользователю отчет:
"Изменено значений остатковэ:" <Колчество измененных данных в поле "Remainder">
"Не найдены следцющие препараты:" <список препаратов, которые не удалось найти в базе данных>. Препараты нужно перечислить в столбик.
