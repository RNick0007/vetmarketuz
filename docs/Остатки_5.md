Команда /medicines
Кнопка "Изменение характеристик препарата"
Скрипт сохранить в файле steps/step_five.py

Пользователь вводит несколько начальных букв наименования товаров и нажимает Интер.
Бот фильтрует препараты из базы данных vetmarket.db таблицы medicnes по полю Name.
Пользователь выбирает товар и нажимает Интер.
Бот открывает карточку товара, где указаны все его характеристики препарата. Бот предлагает: "Выберете параметр, который хотите изменить";
Пользователь выбирает свойство и вводит с клавиатуры новое значение этого свойства, нажимает Интер.
Бот спрашивает пользователя: Изменить значение <наименование свойства> на <введенное пользователем значение>? Под вопросом две кнопки "Да" и "Нет". При ответе "Да" значение выбранного параметра меняется на вновь введенное. При ответе "Нет" никаких изменений в базу данных не вносится.
В качестве отчета бот отправляет пользователю информацию: "Значение поля <наименование характеристики> изменено на <введенное пользователем значение>".
