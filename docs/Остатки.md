При запуске бота должно открыться две команды, команда /start и команда /medicines. Команда /start видна всем пользователям бота. Команда /medicines видна и доступна только администратору бота. Телеграм ID администратора указан в файле .env в константе ADMIN_TG_ID

Команда /medicines. 
Эта команда должна работать только на русском языке. Запустив эту команду администратору бота должно быть представлено 7 кнопок: 
1) Автоматический ввод препаратов;
2) Автоматический ввод остатков; 
3) Ручное изменение остатков;
4) Ввод нового препарата;
5) Изменение характеристик препарата.
6) Удаление одного препарата
7) Удаление всех препаратов

Для реализации всех задач бота создай в корневом каталоге файл bot.py. Этот файл будет являться точкой входа в программу для запуска всех скриптов бота. 
Все файлы, относящиеся к обслуживанию базы данных помести в папку src/danabases.
При выборе "Автоматический ввода препаратов": внеси в файл steps/step_one.py скрипт обработки этой кнопки.
Пользователь вводит в бот .xlsx, .xls, .ods документ.
В загруженном документе не должно быть наименование столбцов. 
Бот последовательно считывает каждую строчку документа. В столбце "A" находит наименование товара, бот ищет данный товар в базе данных data/vetmarket.db в таблице Medicines в поле "Nаме".

Когда товар в базе данных найден:
Меняет значение поля "Before" на за значение из столбца "B" документа;
Меняет значение поля "Unit" на за значение из столбца "D" документа;
Меняет значение поля "Price" на за значение из столбца "E" документа;

Когда товар в базе данных не найден:
Создает новую запись в таблице Medicines и вписывает
Вписывает в поле "Name" значение из столбца "A" документа;
Вписывает в поле "Unit" значение из столбца "D" документа;
Вписывает в поле "Before" значение из столбца "B" документа;
Вписывает в поле "Price" значение из столбца "E" документа;

В обеих случаях, когда препарат найден и не найден:
Бот выходит в Интернет, находит инструкцию по применению данного препарата, желательно на сайт изготовителя препарата и записывает:
В поле "Instruction" ссылку на сайт по инструкции применения;
В поле "Photo" ссылку на изображение препарата;
В полу "Manufacturer" наименование предприятия изготовителя.
