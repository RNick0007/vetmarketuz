Команда /medicines
Кнопка "Ввод нового препарата"
Скрипт сохранить в файде step_four.py
Все ответы пользователя держать в оперативной памяти до нажатия кнопки "Сохранить".

Каждый пункт опроса должен содержать кнопку "Назад" для возвращения на один шаг назад. 

Опрос пользователя:
Введите наименование препарата: значение для поля Name таблицs medicines;
Введите единицу измерения: значение для поля Unit (обязательное поле);
Введите срок годности: введенное значение должно бвть дата в формате "dd.mm.yyyy". Введенное значение для поля Before (обязательное поле);
Введите ссылку на наставление по применению: введенное значение должна быть ссылка на интернет страницу (https://...). Поле Instruction (не обязательное поле);
Введите ссылку на фото препарата: введенное значение должна быть ссылка на интернет страницу (https://...). Поле Photo (не обязательное поле);
Введите цену  препарата: значене для поля Price (обязательное поле);
Введите наименование предприятия изготовителя: значение для поля Manufacturer (Не обязательное поле, допускаются пустые значения);
Введите количестве препарата: значение для поля Remainder (не обязательное поле);
Введите предприятие продавца: значение для поля Salesman (не обязательное поле).

Проверьте правильность введенной информации: бот выводит на экран все вопросы и все ответы, введенные пользователем для ознакомления. В случае обнаружения ошибки или опечатки пользователь нежатием кнопки "Назад" имеет возможность вернуться в тот пункт, в котором допущена ошибка вновь вернуться в этот же пункт меню и нажать кнопку "Сохранить". После нажатия на кнопку "Сохранить" бот записывает информацию в соответствующие поля и выводит отчет: "Информация о препарате записана в базу данных".

Ели пользователь кнопкой "Назад вернулся в какой-то пункт меню, исправил информацию и нажал клавишу Инер, то его сразу нужно возвращать в тот пункт опроса, откуда он впервые нажал кнопку "Назад".
