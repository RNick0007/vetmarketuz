Команда /medicines
Кнопка "Удаление всех препаратов"
Скрипт сохранить в файле src/steps/step_seven.py

Пользователь нажимает кнопку "Удадение всех препаратов";
Бот спрашивает: "Удалить все препараты из таблицы Mtdicines?"; Предлагает пользователю две кнопки "Да" и "Нет".
При выборе пользователем "Да" из базы данных удаляются все препараты и база данных оптимизируется.
