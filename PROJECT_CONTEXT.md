Название проекf
VetMarketUz

Цель проекта

    В проекте будет созан Телеграм бот который автоматизирует оптовую продажу ветеринарных препаратов покупателям. В роли покуателей будут выступать такие предприятия как ветеринарные клиники, ветеринарные аптеки и зоомагазины, имеющие лицензию на ветеринарные услуги в республике Узбекистан. Бот будет написан на языке python, в бот будет внедрена база данных SQLite для хранения информации о ветеринарных препаратах, о покупателях и о движении товаров. 

Основные функции
    1) Автоматизированный ввод в базу данных SQLite намиенований ветеринарных препаратов, имеющихся на складе. Ввод будет осуществляться загрузкой в бот .xlsx, .xls или .ods документа;
    2) Автоматизированный ввод в базу данных количественного остатка ветеринарных препаратов. Ввод будет также производиться загрузкой в бот докуменрв в формате .xlsx, .xls или .ods;
    3) Ввод в баз данных ветеринарных препаратов в ручном режиме;
    4) Ввод остатка товаров в ручном режиме;
    5) Изменение параметров ветеринрного препарата в ручном режиме;
    6) Удаление из базы данных одного ветеринарного препарата;
    8) Удаление из базы данных всех ветеринарных препаратов:
    9) Выбор покупателем ветеринарных препаратов для покупки;
    10) Регистрация нового покупателя;
    11) Создание zip архива с собранной от покупателя информацией;
    12) Создание предварительной накладной с выбраными покупателем товарами;
    13) Отправка zip архива и предварительной накладной на модерацию.  
...

Что реализовано
    1) Точка входа Telegram-бота в bot.py; команды /start и /medicines на русском языке; меню препаратов отображается встроенными кнопками над строкой ввода;
    2) Команда /medicines и административные действия доступны только для ADMIN_TG_ID из .env;
    3) Обработка кнопки «Автоматический ввод препаратов»: импорт .xlsx, .xls и .ods без заголовков, немедленное сохранение записей Medicines и фоновый поиск дополнительной информации через Brave Search API. Для поиска задается BRAVE_SEARCH_API_KEY в .env; уже загруженные записи с незаполненными полями можно обработать командой `docker compose exec bot python -m src.databases.enrich_missing`;
    4) Обработка кнопки «Автоматический ввод остатков»: загрузка .xlsx, .xls и .ods без заголовков, поиск препарата по столбцу A и обновление Remainder значением из столбца B; остатки поддерживают до двух знаков после запятой, неизвестные препараты и ошибки данных включаются в отчет. При обработке файла во всех записях Medicines поле Salesman устанавливается в Vetco. Для старых баз данных выполняется миграция типа Remainder с INTEGER на REAL.
    5) Обработка кнопки «Ручное изменение остатков»: поиск препарата по началу наименования, просмотр карточки со всеми характеристиками и фото, проверка и сохранение нового остатка.
    6) Обработка кнопки «Ввод нового препарата»: пошаговый опрос с проверкой значений, хранение незавершенной анкеты в оперативной памяти, возврат к предыдущим пунктам и сохранение в Medicines только после подтверждения.
